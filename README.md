# Ryzen

My personal site and blog. It has a feed of posts, Instagram-style stories, an about page, and a 3D turntable built with Three.js. Content is managed in Sanity, and the whole thing is built to deploy on Vercel.

The design is neo-brutalist: thick borders, hard shadows, loud type.

## What's in it

- **Blog feed** with live search (titles are matched against Sanity as you type)
- **Article pages** that render Sanity Portable Text, loaded by slug (`article.html?slug=...`)
- **Stories** that open in an overlay. The story is tracked in the URL (`?story=...`), so the browser's back button closes it
- **3D turntable** (Three.js, GLB models in `public/models/`) with a tonearm that animates with playback
- **Spotify endpoint** (`api/spotify.js`), a serverless function that returns what I'm playing right now or my last played track, with a 30-second preview pulled from iTunes or Deezer when one exists
- **Typed.js** intro text and **Vercel Analytics**

## Content model

Defined in `ryzenpo/schemaTypes/`:

- **post**: title, date posted, author, poster image, content (Portable Text), slug
- **stories**: story image, author, date posted, slug
- **user**: author name

## Getting started

You need Node.js 18 or newer.

### Frontend

```bash
cd frontend/ryzen-frontend
npm install
npm run dev
```

Other scripts: `npm run build` and `npm run preview`.

### Sanity Studio

```bash
cd ryzenpo
npm install
npm run dev
```

Other scripts: `npm run build` and `npm run deploy`.

To point the site at your own Sanity project, change the project ID and dataset in `frontend/ryzen-frontend/src/sanityConfig.js`, `ryzenpo/sanity.config.ts`, and `ryzenpo/sanity.cli.ts`.

### Spotify endpoint

`api/spotify.js` runs as a Vercel function, so `npm run dev` (plain Vite) won't serve it. Use the Vercel CLI instead:

```bash
npm i -g vercel
vercel dev
```

It needs these environment variables, set in the Vercel dashboard or in a local `.env.local` file:

```
SPOTIFY_CLIENT_ID=
SPOTIFY_CLIENT_SECRET=
SPOTIFY_REFRESH_TOKEN=
```

You get the refresh token by running Spotify's authorization code flow once for your own account. The scopes needed are `user-read-currently-playing` and `user-read-recently-played`.

## Deployment

Import the repo into Vercel and set the root directory to `frontend/ryzen-frontend`. Vercel will pick up the Vite build and the `api/` folder on its own. Add the Spotify variables above in the project settings.
